# 分镜访谈与制作

## 按回答追问

先确认交付是审校、定时分镜、模型提示词、动态分镜、交互动画或成片。素材、时长和输出端有实质冲突时优先询问。选择 1–3 项逐轮确认。

| 已明确的方向 | 可追问的决定 |
|---|---|
| 有故事梗概或参考片 | 观众在结尾必须看懂什么？哪些情节、镜头或构图需要保留？哪些可以合并或重排？ |
| 有参考图编号 | 每张图对应角色、道具、场景、视角还是风格？原图是否已上传？同一角色的服饰、比例、惯用手和道具位置有哪些必须保持？ |
| 有目标片长 | 目标含片头、片尾和黑场吗？有没有锁定时长的镜头？总和不足时更适合延长动作、留反应时间还是补镜？ |
| 片子在展馆循环播放 | 屏幕通常静音吗？观众中途开始看能否理解？片尾直接切回、匹配构图还是无缝循环？成品首次露出和停留几秒？ |
| 已有视觉方向 | 哪个是交付画幅与帧率？时间、主光和相机运动有哪些限制？需要哪种目标工具可直接使用的提示词？ |
| 声音会影响叙事 | 哪些台词、字幕、旁白、音乐或环境声需要保留？镜头之间哪些声音应提前进入或延续？ |
| 有交互 | 观众在哪一帧获得操作提示？触发后有哪些声画反馈？不操作、重复操作或回放时怎样恢复？ |

## 从剧本到可执行分镜

1. 汇总全局风格、输出规格、声音规则和资产映射。逐个标记实际收到、仅有文字指代、待补或需核对许可的素材。把风格用可执行的造型、色彩、光线和材质描述表达清楚。
2. 逐镜写起止时码、时长、景别与角度、构图与运镜、主要动作和情绪、光影、声音及必要的特效或台词。交互镜头另写触发、反馈和回退。提示词交付时，提供可复用的全局控制和可独立复制的镜头内容，沿用用户指定工具的输入格式。
3. 按同一单位累计，检查镜头时码无空档、无重叠且总长匹配。审校只报告差值和影响。用户要求修订时，保留明确锁定的动作、时长和叙事顺序；将增加或删减的时间分配到动作完成、反应、过渡或停留上。需要以帧交付时统一按指定帧率核对。
4. 对照相邻镜头的方向、机位、动作起止、道具去向、人物站位和环境声。遇到「固定」与「跟拍」同镜冲突时，明确机位实际如何变化。若只完成文字试跑，交付可读可核算的分镜，并按真实素材和制作状态报告。
