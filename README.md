# 数媒立项与样片访谈

`digital-media-prototype` 是一个 Codex Skill。它把聊天记录、赛题和已有素材整理成制作任务，通过分轮访谈确认细节，再按需求交付一周立项方案、游戏小样、短片分镜或静态设计样稿。

## 开始使用

在当前项目的 Codex 对话里，附上希望沿用的聊天、赛题或素材，用下面这段话开始访谈。

```text
用 $digital-media-prototype，读取我提供的聊天和素材。
从《顺时而生》开始，每轮问我 1–3 个关键问题，确认后做一个可试玩小样。
```

如果要带到另一个 Codex 项目，解压 `digital-media-prototype.zip`，将整个 `digital-media-prototype` 文件夹放入目标项目的 `.agents/skills/`。随后在目标项目中用 `$digital-media-prototype` 调用。

## AI 会怎么问

1. 先复述已经确认的目标、方向和交付形式，沿用聊天里已有的答案。
2. 每轮追问 1–3 个会影响下一步的问题。你可以直接回答、暂时跳过，或让 AI 给出暂定值。
3. 根据你的回答继续追问制作和验收细节。关键信息够用时，AI 会记录暂定项与待补素材，然后开始制作和检查。

| 方向 | 可能追问 | 常见交付 |
|---|---|---|
| 一周立项 | 哪个方向优先？谁负责制作？一周后要展示什么？ | 各方向的最小样品、分工、日程、验收与资源台账 |
| 游戏与交互 | 玩家什么时候能看到提示？第二个副本怎么解锁？个人记录如何保存？ | 可操作的核心流程、选择反馈和测试结果 |
| 动漫与短片 | 哪些动作必须保留？总时长含片尾吗？参考图、字幕和声音有什么要求？ | 带时码的逐镜脚本、提示词或动态分镜规格 |
| 静态设计 | 样稿在哪展示？读者会停留多久？看完要能做出什么判断？ | 版式草图、代表样稿或对照卡及验收标准 |
